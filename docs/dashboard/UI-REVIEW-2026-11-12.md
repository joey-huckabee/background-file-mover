# Dashboard UI review, 2026-11-12

Live review of the read-only dashboard (increments 130–132) with the user, page by
page, on a disposable local demo. Decisions below are the user's; they drive the
UI refinement increment and two small contract extensions the user approved.

## Sign-in

- Keep the brand panel and tagline. Remove "Transfers continue independently of
  dashboard sessions."
- Remove "Use the host-managed administrator account." and "Account setup and
  password changes are host-local." Errors stay inline.

## Job history

- Remove the Generator column (fixed per instance; stays in job detail).
- Replace State/Condition with one **Progress** column (mockup option A): steps
  **Received › Acquired › Moved | Copied** plus a badge only when attention or
  waiting applies (Waiting for files, Ready to deliver, Retrying delivery, Needs
  review). "Moved" when source cleanup after delivery is enabled, else "Copied"
  (currently always Copied; production source deletion is disabled).
- No separate Source files column (the Acquired step covers custody).
- Keep the Job # / ID column. Label the UUID **Request ID**.
- Add **Files delivered**, **Size**, **Source folder**, **Destination folder**
  (folders relative to the configured roots; roots appear on Settings).
- Every column header has hover text explaining it.
- Keep oldest-first default; add server-side **Job ID ascending/descending** sort.
- Remove "Session ends after 30 minutes…" and the read-only footer note.
- Contract extension (approved): list summary gains file counts, size, relative
  folders and copy/move mode; list gains an order parameter.

## Job detail

- Opens **inline**: the selected row expands, with the detail between that job
  and the next one (accordion), not below the whole table.
- Show **all** facts in plain wording with hover text; exact technical values
  stay visible in the hover for troubleshooting.
- Files table: **File | Status | Size | Attempts**. Status reads Waiting /
  Acquired / Verified / Delivered with the transfer phase in its hover; Size is
  human-readable with exact bytes in the hover.
- Show the job's storage reservations **inline** (no button), and lay the detail
  out to use the available width (for example facts, reservations and files in a
  multi-column grid rather than one long column).

## Admin connections

- Allow multiple independent browser connections to the admin listener (it now
  admits one at a time). Fix soon, before live updates; keep a guaranteed slot
  for the private operator socket within the global budget.

## Settings (new, read-only)

- New admin page showing configuration, including filesystem paths (roots, state,
  account and certificate file paths). Never secrets or file contents.
  Contract extension (approved): one new read-only admin route. Other admin-area
  content to be discussed later.

## Roadmap additions

- Event-pushed status updates without polling or full-page refresh (see ROADMAP).

## Open

Remaining review pages: job detail specifics, retention, settings layout.
