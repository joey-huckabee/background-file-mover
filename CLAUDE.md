# Project instructions

Read [AGENTS.md](AGENTS.md) for the authoritative current direction, approval
boundaries, safety constraints and Git conventions.

The implementation is Rust in `rust/`. Start each bounded change on a short-lived
branch from `main`, preserve qualified evidence, complete applicable SLES gates
and independent review, then merge through a PR. See
[the agent workflow](docs/AGENT-WORKFLOW.md). Release/deployment and operational
state changes remain separate authorizations.
